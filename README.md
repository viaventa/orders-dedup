# orders-dedup

Сервис забирает «сырые» заявки с `https://test.ooobs.ru/api/orders`, нормализует телефоны, схлопывает дубли и отдаёт результат в JSON.

**Живой URL:** _появится после деплоя_

## Правила

- Телефон очищается от всего, кроме цифр, и приводится к `+7XXXXXXXXXX`: 11 цифр с ведущей `7` или `8`, либо 10 цифр без кода страны. Остальные номера отбрасываются как невалидные.
- Дубли ищутся по нормализованному телефону. Остаётся запись с максимальным `amount`, при равных — более поздняя по `created_at`.
- Клиенты идут в порядке первого появления телефона в исходных данных.

## Идемпотентность

Состояния между запросами нет: каждый запрос к `/result` заново забирает заявки и пересчитывает результат. Одинаковые входные данные всегда дают одинаковый ответ, и повторная синхронизация не может накопить дубли. Это проверяет тест, который подаёт заявки дважды.

## Секреты

Секретов в задаче нет, источник публичный. Его адрес вынесен в переменную окружения `ORDERS_URL` (пример — в `.env.example`, сам `.env` в `.gitignore`). На Vercel переменные задаются в Project Settings → Environment Variables, в репозиторий они не попадают.

## Запуск

Нужен Node.js 20+, зависимостей нет.

```bash
npm start   # http://localhost:3000/result
npm test    # юнит-тесты на node:test
```

## Структура

```
├── api/result.js        # обработчик: забирает заявки и отдаёт JSON (функция Vercel)
├── lib/clients.js       # нормализация телефонов и дедупликация
├── server.js            # локальный запуск или любой Node-хостинг
├── test/                # тесты и пример данных из /api/orders
└── vercel.json          # /result → /api/result
```
